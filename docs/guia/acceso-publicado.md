# Aplicación y documentación publicadas

SoccerLeague dispone de una aplicación desplegada para explorar los módulos y de un sitio de documentación con información funcional y técnica del proyecto.

| Recurso | Dirección |
| --- | --- |
| Aplicación web | [soccer-league-orcin.vercel.app](https://soccer-league-orcin.vercel.app/) |
| Documentación | [soccer-league.br4vo-code.workers.dev](https://soccer-league.br4vo-code.workers.dev/) |

## Acceso de visitante

Para realizar pruebas de consulta, abre la aplicación e inicia sesión con esta cuenta de demostración:

| Campo | Valor |
| --- | --- |
| Usuario | `visitor@soccerleague.com` |
| Contraseña | `Visitor1234` |
| Rol | `visitante` |

El visitante puede consultar equipos, jugadores, entrenadores, estadios, temporadas, partidos, estadísticas y reportes, y exportar los reportes en PDF. La cuenta no tiene permisos de edición: no puede crear, modificar ni eliminar datos, ni administrar cuentas de usuario. El control de acceso se aplica tanto en las pantallas como en la API.

## Recorrido de prueba

1. Iniciar sesión y recorrer el panel y los módulos de consulta.
2. Abrir un partido y revisar su marcador y las estadísticas individuales.
3. Seleccionar una temporada o los parámetros de un reporte y consultar sus resultados.
4. Exportar un reporte en PDF.
5. Cambiar entre español e inglés y entre los temas claro y oscuro.
6. Consultar la documentación de los módulos para conocer el funcionamiento del sistema.

Las pruebas de altas, modificaciones, bajas y transferencias se realizan en un entorno local de prueba con una cuenta administrativa. El acceso publicado de visitante está destinado a la consulta.
